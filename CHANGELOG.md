## [Unreleased]

### Added
- Glove- and remote-friendly home launcher for the DMD2 navigation device.
- **Home screen and orientation.** Home is a grid of 12 large tiles — 11 configurable favourite slots plus a dedicated "All Apps" tile — laid out 4×3 in landscape and 3×4 in portrait, fully operable by the handlebar remote (dpad + Enter + Escape), which moves a highlight between tiles; there is no swiping anywhere. Which shape shows follows the Orientation setting in the All Apps settings mode: tapping it opens a picker listing Landscape, Portrait, Reverse landscape, Reverse portrait and Sensor and applies only the one chosen, so the screen never rotates through the other orientations on the way. Sensor, the default, follows the device's accelerometer and auto-rotates between all four orientations regardless of Android's own auto-rotate switch: choosing it here is the choice. Coming back from an app, the remote's highlight is still on the tile it launched, unless the screen rotated in the meantime.
- **Tile long-press menu.** Short tap / Enter launches an app; a touch long press opens a tile-styled menu with large buttons. On a Home favourite it offers **App info** (the system app-info screen), **Uninstall** (hands the app to the system uninstaller) and **Remove**, which clears the slot and turns it back into an empty "+" tile; tapping "+" opens the app picker for that slot, so favourites are configured in place; the picker starts with a None tile that clears the slot, and uninstalling an app clears any slot that held it. In the All Apps list the same menu offers **App info**, **Uninstall** and **Hide** — **Unhide** for a hidden app — and a "Hidden apps" settings tile (in the All Apps settings mode) toggles between Hidden (default) and Showing (dimmed), letting you review and recover hidden apps without cluttering the list during normal use. Back or Escape closes the menu. It opens on a touch long press only — holding Enter on the remote never opens it, so the remote can only ever launch.
- **Link tiles on the home screen.** When picking what goes into a favourite slot, an "Add link" tile puts a web address or other link in the slot instead of an app. The dialog asks for a name and a link; Android opens it with whatever app handles that kind of link, so deep links and app-specific schemes work the same as web addresses. Long-pressing a link tile on the home screen opens an "Edit link / Remove" menu; Edit link re-opens the dialog with the current name and link filled in.
- **All Apps screen.** A scrollable, remote-navigable grid of every launchable app, minus the ones you have hidden, with a touch-only back button and a search field to filter long lists. Screens switch instantly, with no transition animation.
- **Settings mode** in the All Apps screen: configuration is a touch-only workflow with no separate settings screen — tapping an empty "+" tile on the home screen opens the app picker for that slot directly, the tile menus handle the rest of favourites and hiding in place, and the device-wide settings sit behind the "Settings" toggle in the All Apps header, which switches the grid from the app list to text-only settings tiles (theme, navigation app, update check, park lock, cellular indicator, GPS speed and units on devices with GPS, battery display, hidden apps, orientation, navigation bar); the search field stays and filters those tiles, tapping "Settings" again or a short Escape returns to app browse mode (a second Escape returns to the home screen, while a short Escape on the home screen does nothing), and switching the theme keeps you in settings mode. The header row — back button, search field and "Settings" toggle — is touch-only, so the remote can never land on it, while the search field can still be tapped and typed into; the "All Apps" home tile simply opens the app list and has no long-press.
- **Theme.** Dark/Light toggle in the All Apps settings mode (defaults to dark); the choice is saved and restored on restart.
- **Navigation app setting.** A settings tile in the All Apps settings mode lets you pick any app from the All Apps list as the navigation app (hidden apps are offered only while "Hidden apps" is set to Showing); the picker's None tile clears it. Holding Escape on the remote launches this configured app, from the home screen and from the app list alike. No navigation app configured, or one that has since been uninstalled, does nothing.
- **Update check.** User-triggered update check from the All Apps settings mode, with download and hand-off to the system installer (no automatic polling — the device is mostly offline). While an update is downloading, the tile shows percentage and speed (e.g. `45% · 2.2 MB/s`), refreshed about twice a second. The installer file is deleted once the update it carried is running, and any earlier download is removed when a new one starts, so at most one update APK ever sits in the app's cache.
- **Park lock.** A manual PIN lock for short unattended stops, in All Apps → Settings → Park lock. The launcher stays free of any system lock screen — there is no device PIN to fumble with at a red light. The first tap on Park lock sets a PIN (entered twice); from then on tapping it puts up a glove-sized keypad and asks Android to pin the screen, which blocks Recents and the notification shade, and long-pressing the tile changes the PIN. The correct PIN releases the lock, and nothing re-locks on its own. Parking is a single tap — Android does not ask an app to confirm pinning itself. Where pinning is unavailable the park screen still holds against the Home gesture. Android's own unpin gesture (hold Back + Recents) cannot be blocked, so the park screen undoes it: while parked it re-pins itself within a few hundred milliseconds, and only the correct PIN stops that. **Note the consequence: while parked, the PIN is the only way back in** — a forgotten PIN locks you out of the device until the launcher is reinstalled from a computer.
- **Status bar.** A custom home status bar in the bundled Michroma font (SIL Open Font License 1.1 — see `MICHROMA-LICENSE.txt`), showing the current time on the left and Wi-Fi, cellular, and battery indicators on the right, aligned with the grid margins on tablet-sized screens. The signal meters show their bars down to zero rather than disappearing: the Wi-Fi icon is hidden only when the radio is off, the cellular icon only when its indicator is off or the launcher has no access to the signal. The battery icon fills in five steps with the charge level and shows a lightning bolt while a charger is connected.
- **GPS speed display** in the home screen status bar — between the clock and the status icons in landscape, on its own row below them in portrait. Off by default; turned on from the settings mode in the All Apps screen (the tiles appear only on devices with GPS), where the first tap makes Android ask for location permission and the tile switches to On as soon as it is granted. A Units tile (Metric / Imperial), shown as the current unit (`km/h` or `mph`), picks what the speed is displayed in. Speed is only read while the home screen is showing and the display is on, so it costs nothing while the navigation app is in front.
- **Cellular indicator** in the home screen status bar, off by default. Turning it on makes Android ask for permission to read the phone's signal state; the tile shows On or Off according to the answer straight away. Needs Android 12 or newer — on Android 11 the toggle can be switched on but no icon appears.
- **Battery display setting.** A settings tile cycles between Icon + text (default), Icon only, and Text only. The status bar updates immediately on change.
- **Navigation bar setting.** The Android status bar is always hidden so the full screen is available for the launcher's own UI; the Android navigation bar is a settings tile that toggles between Hidden (default) and Visible, and the home grid and app list automatically make space for the bar when shown.
- **Phone / small-screen support.** All text, icons, padding and tile heights are sized for a 7-inch tablet-class screen like the navigation device, and scale down on phone-sized screens so the launcher stays usable there too.
