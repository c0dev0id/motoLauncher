# Privacy policy

Effective 2026-10-19. Applies to motoLauncher from Google Play and from the GitHub
release page.

motoLauncher collects no personal data and shares none. It has no accounts, advertising,
analytics or tracking.

Everything the launcher stores — favourites, links, hidden apps, settings, and the park
lock PIN, which is kept only as a salted hash — stays in its private storage on the
device. If Android backup is switched on, Android may include these settings in the
device backup.

The list of installed apps is read only to show and launch them.

With the GPS speed display switched on, the launcher reads the device location while the
home screen is visible, to show the current speed. The location is neither recorded nor
sent anywhere.

The status bar reads the Wi-Fi signal strength and, with the cellular indicator switched
on, the mobile signal strength, to draw its signal bars.

The Google Play version makes no network connections. The version from the GitHub release
page connects to GitHub only when you tap the update check, to look for and download a
newer version.

Questions: https://github.com/c0dev0id/motoLauncher/issues
